# Independent Brian2 regression fixtures

The one-second sugar/P9 event schedules and expected spikes were produced by
Brian2 2.8.0 float64 C++ standalone using numerical candidate `72627c7` in
[PraxisMechanica/fly-brain-mlx](https://github.com/PraxisMechanica/fly-brain-mlx/tree/72627c714ba6941e017b4585ff3d77bd20a4dfde).
They use FlyWire v783, 0.1 ms steps and PCG64 seed 20261004, trial 0.
Expected counts: sugar 16,752; P9 858. Input JSON binds channel setup and event
hashes. NPZ arrays contain ordered integer steps, neuron rows and FlyWire IDs.

The expected arrays are independent reference output, not generated by MLX.
They were compacted from retained `m5-pilot-02/isolated-brian-{sugar,p9}`
`spikes.npz` files by retaining rows/steps and looking up each spike's FlyWire ID;
unused full-network identifier/count arrays were removed. Original archive SHA-256:

- sugar: `526602032715b0981a5369826ef660071499845a4d12b51b317daad7bb4b6fc4`
- P9: `68ee772d264db00c958dc891e1e85c5e496d90ba0dd2c90dfb6030803eac5d44`

The focused tests require exact spikes, mapping and empty-output types. Historical
campaign summaries and run receipts are intentionally outside this contribution.
